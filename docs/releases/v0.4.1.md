# floating todo v0.4.1

v0.4.1 正式版汇集 rc.1–rc.3 的更新与重构改进，带来迷你悬浮栏贴边展开与最近任务叠层、毛玻璃与平面阴影双模式统一界面样式、紧凑模式（Compact）排版修复，以及代码清理与移动端架构前置解耦。

## 功能与体验更新

### 迷你悬浮栏贴边展开与最近任务叠层（rc.1 / rc.2）

- **贴边自适应展开**：在迷你悬浮栏状态下展开快捷新增或最近任务预览时，窗口会根据屏幕剩余空间自动选择向上/下、向左/右方向展开，保持胶囊栏本身在屏幕上的锚点位置不变。
- **最近任务叠层与原地完成**：点击悬浮栏右侧箭头先展示最近任务叠层预览，再次点击箭头或首张卡片可展开最多 3 条优先待办（按今天、明天、后天顺序选取未完成任务）；卡片左侧支持直接点击勾选完成任务，并自动顺延补入下一条待办。
- **卡片材质统一**：迷你悬浮栏与最近任务卡片共享统一的主题、背景色、毛玻璃/平面材质与透明度配置。

### 毛玻璃与平面阴影双界面模式（rc.3）

- **双表面样式**：在「设置 → 外观 → 界面样式」中支持切换 **毛玻璃（Liquid Glass）** 与 **平面阴影（Flat）** 两种模式（macOS 默认毛玻璃并启用原生 `NSVisualEffectView` 精准内缩圆角材质；Windows 默认平面阴影）。
- **平面模式窗口阴影开关**：在平面阴影模式下可独立开启或关闭窗口外阴影，重启与导出备份均可保留配置。
- **设置与二级面板规范化**：统一所有弹窗顶栏、分段控制器、开关组件（`.switch` / `.toggle-switch`）与列表间距。

### 紧凑模式（Compact）UI 重构与代码清理（v0.4.1）

- **紧凑模式排版修复**：将紧凑模式顶部的分类筛选栏与放大按钮放入同一弹性顶栏容器（`.compact-topbar`），并将任务行中的项目/标签指示圆点改为标题右侧单行内联展示，修复了小窗口下分类标签导致的按钮重叠与卡片错位问题。
- **窗口缩放简化**：移除左下角拖拽缩放到极限时自动跳入 Mini 模式的冗余手势，统一使用八方向原生边缘缩放与顶栏计数胶囊切换。
- **v3 存储精简与移动端解耦**：清理早期遗留目录与旧版（v1/v2）`localStorage` 迁移代码，保持与 `v0.4.1-rc.3`（`todo-v3.sqlite3` 及 v3 Revision DAG 同步协议）100% 兼容，并完成 Rust 桌面专属能力（托盘/快捷键/窗口控制）与跨平台凭据层的解耦。

| --- | --- |
| macOS · Apple 芯片 | `floating-todo_0.4.1_aarch64.dmg` |
